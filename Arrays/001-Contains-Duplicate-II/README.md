## Problem 1: Contains Duplicate II

- **Platform:** LeetCode
- **Difficulty:** Easy
- **Topic:** Hashing

### Problem Link
https://leetcode.com/problems/contains-duplicate-ii/

### Approach
1. Create an empty dictionary.
2. Traverse the array using a loop.
3. Check whether the current number is already present.
4. If present, check whether the index difference is less than or equal to k.
5. Return True if the condition is satisfied; otherwise return False.

### Time Complexity
O(n)

### Space Complexity
O(n)

### What I Learned
Learned how to use dictionaries to store numbers and their indices.
